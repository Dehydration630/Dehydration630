### LeitCue / 乐叙 · 整集剧情配乐工作台

让漫剧与剧情短视频创作者，从一段待配乐视频，走到可试听、可调整、可导出的整集结果。

- **从用户问题出发**：通过访谈、真实任务与反例，校正「好听」和「愿意采用」之间的差距。
- **把模型能力变成产品流程**：叙事规划、分层字段、按功能选模型、自动选段与整集装配。
- **用评测推动取舍**：保留失败案例，区分模型效果、剪辑贡献和技术成功，兼顾质量与成本。

### MelCue / 乐话 · 音乐人的 AI 乐迷与陪伴助手

让音乐人在成名之前，也能感到自己的作品被认真在意。从听歌交流、自然跟唱，到一起写一句歌词、用日常素材获得下一条内容的灵感。

- **通过反例收敛定位**：从全流程宣发工具，转向持续的作品交流与陪伴，让工具在对话中自然出现。
- **把体验落实为系统规则**：完整乐句跟唱、认可后保存歌词、先有可行剪法再邀约；将聊天、任务与结果投递分开管理。
- **用真实体验校正模型**：比较自然度、听感与配乐匹配度，保留失败案例，明确已验证能力与上线边界。

[一页产品案例](https://github.com/Dehydration630/melcue-demo/blob/main/docs/CASE_STUDY.md) · [设计决策与复盘](https://github.com/Dehydration630/melcue-demo/blob/main/docs/DECISIONS.md) · [模型评测](https://github.com/Dehydration630/melcue-demo/blob/main/docs/EVALUATION.md) · [架构与测试](https://github.com/Dehydration630/melcue-demo/blob/main/docs/ARCHITECTURE.md)
